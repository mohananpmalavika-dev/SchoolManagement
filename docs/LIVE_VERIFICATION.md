```powershell

```

The script checks HTTPS login, actual API liveness/readiness, anonymous payment-settings denial, authenticated settings secret redaction, CCTV gateway/MediaMTX health, anonymous camera-registry denial, cross-tenant media denial, and signed-versus-unsigned reads of an existing private QA object when configured. Local TCP checks are loopback only. An authenticated settings response proves API access, not provider authentication or settlement.

## Backup evidence and objectives

RPO <1 hour and RTO <30 minutes are **targets, not measured achievements**. A `pg_dump` snapshot does not provide WAL/PITR. The implementation uses gzip plus authenticated AES-256-GCM for new backups, retains legacy CBC decryption, and invokes `psql` with `ON_ERROR_STOP=1` and a single transaction. The existing isolated backup fixture creates its own archive with a random key; it does not exercise production key recovery or downloading an offsite archive.
